# Student Registration & Result Portal

A responsive front-end mini project built with **HTML5, Bootstrap 5 and JavaScript**. Students enter their details and marks, and the portal validates the input, calculates the result and displays it instantly.

## Features
- Student registration form (name, roll number, email, phone, course)
- Marks entry for 5 subjects
- Form validation with error messages
- Automatic total, percentage, grade and Pass/Fail status
- Result card with a subject-wise progress bar
- Table of registered students that updates dynamically
- Responsive layout for mobile, tablet and desktop

## Technologies
| Technology | Use |
|---|---|
| HTML5 | Page structure and forms |
| Bootstrap 5 | Layout, cards, buttons, tables, alerts |
| CSS3 | Custom styling |
| JavaScript | Validation, calculation, DOM manipulation |

## Pass Rule
A student passes only if they score **35 or more in every subject**.

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any browser (internet needed for the Bootstrap CDN).
